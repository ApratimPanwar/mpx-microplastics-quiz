Set up automatic collection (one-time, ~5 minutes)

By default, the quiz only lets each respondent download their own response — nothing is centrally collected until you do this one-time setup:

  1. Create a new Google Sheet, then go to Extensions → Apps Script and paste in the code from the AppsScript-Code.gs file provided alongside this dashboard.
  2. Click Deploy → New deployment → Web app. Set "Execute as: Me" and "Who has access: Anyone", then deploy and copy the Web App URL.
  3. Open the quiz HTML file, find the line const SUBMIT_URL = ""; near the top of the script, and paste your Web App URL between the quotes. Re-share/re-host the quiz file after this edit.
  4. Every completed quiz now appends a row to your Google Sheet automatically.
  5. To view that data here live: in the Sheet, go to File → Share → Publish to web, choose the response sheet/tab and CSV format, and paste the resulting URL into the "Fetch" box above. Otherwise, just download the Sheet as CSV (File → Download → CSV) periodically and drop it into the loader above.
